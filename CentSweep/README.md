# CentSweep Website

A static landing page for the **CentSweep** iOS application.

## Overview
CentSweep allows users to clear their remaining Apple ID balance down to zero using calculated In-App Purchases, enabling them to change their App Store region freely.

## Tech Stack
- HTML5 / CSS3 / Vanilla JavaScript
- Zero dependencies, no frameworks, no build tools
- Split-screen two-panel responsive architecture
- i18n support for 7 languages (EN, RU, FR, DE, ES, IT, HY)

## Structure
- `index.html`: Main landing page with interactive panels (Features, Screens, Guide, About, Support, Privacy)
- `assets/`: Contains `main.js`, `split-style.css`, icons, mockups, screenshots, and videos.
