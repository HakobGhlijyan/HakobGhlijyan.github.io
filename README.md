# iOS Developer Portfolio (Template)

Files included:
- index.html — main single-page portfolio
- styles.css — responsive, accessible styles with light/dark theme support
- script.js — theme toggle and small behaviors

How to use:
1. Place these files in a project folder and open `index.html` in a browser.
2. Replace placeholder text (email, links, projects, experience) with your real content.
3. Update the favicon or logo as desired.
4. If you want to host it, push to any static host (GitHub Pages, Netlify, Vercel).

Customization ideas:
- Replace project card "View" links with App Store links or GitHub repos.
- Add screenshots into `.device .screen` or inside project cards.
- Integrate analytics or contact form backend (currently it uses mailto).
- Add additional pages (resume, blog) or convert to a static site generator.

Accessibility notes:
- Colors have been chosen for good contrast; test with Lighthouse or a11y tools.
- Focus outlines are visible; keyboard navigation is supported.
